About

What is this?

cvelistV5_fetcher imports the CVE Program's public CVE 5.0 feed into a local database and puts a search page and dashboard on top of it. Each raw record is normalized into a simple schema — severity, CVSS score, affected vendors and products, description, and reference links — and served through this UI and a documented REST API at /docs.

It's a proof-of-concept, not a production vulnerability feed: there's no alerting, no deduplication against other sources, and no long-term support commitment. It exists to show the fetch → parse → store → search pipeline end to end, on real data.
